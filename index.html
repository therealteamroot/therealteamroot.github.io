Notice: Antivirus Flags and False Positives

  • Why this happens: The toolkit utilizes historic local privilege escalation exploits (such as rageagainstthecage and zergrush) to gain root access on old Android systems. Antivirus engines recognize these code signatures as security flaws, even though they are used here safely and intentionally for device modding.
  • Security Assurance: This project contains no malware, spyware, trojans, or remote-access payloads. The complete source code of the wrapper scripts is open and visible in this repository for audit.
  • Resolution: If your security suite blocks the toolkit, you will need to add an exclusion rule for the installation folder or temporarily pause real-time protection during data transfers over the ADB interface.

Warning: Risk of Device Malfunction (Bricking)

  • Soft-Bricks: Bootloops or failing to initialize system daemons can usually be recovered by entering Fastboot mode or using factory recovery utilities (such as Odin for Samsung devices).
  • Hard-Bricks: Interrupting low-level flashing operations, corrupting sector 0 of boot storage, or applying incorrect engineering parameters can result in a hard-brick. A hard-brick renders the phone completely unresponsive and un-bootable.
  • User Responsibility: This software is provided "as-is" without any warranty. You assume all responsibility and risk when executing these tools on your hardware. Ensure your phone has a stable battery charge and a secure Micro-USB connection before initiating any flashing actions.
